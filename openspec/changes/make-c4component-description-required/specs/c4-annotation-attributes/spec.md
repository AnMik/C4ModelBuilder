## MODIFIED Requirements

### Requirement: Разметка компонента атрибутом C4Component

Пакет SHALL публиковать атрибут `C4ComponentAttribute` (`C4Component`), применимый к классу,
интерфейсу и методу. Описание SHALL быть обязательным первым параметром конструктора:
`C4ComponentAttribute(string description, bool isRoot = false)`, где `description` SHALL быть
не-nullable. Корневой компонент SHALL задаваться вторым параметром конструктора `isRoot` со
значением по умолчанию `false`. Свойства `Description` и `IsRoot` SHALL предоставляться только
для чтения и SHALL отражать значения параметров конструктора.

#### Scenario: Разметка корневого компонента

- **WHEN** класс помечен атрибутом `C4Component` со значением `isRoot = true`
- **THEN** разметка компилируется, и класс становится точкой входа анализа

#### Scenario: Разметка компонента с описанием

- **WHEN** тип помечен атрибутом `C4Component` со значением описания
- **THEN** указанный текст используется как описание компонента на сгенерированной диаграмме

#### Scenario: Разметка компонента на методе

- **WHEN** метод помечен атрибутом `C4Component` со значением описания
- **THEN** узел вызова этого метода становится компонентом диаграммы с указанным описанием

#### Scenario: Разметка без описания

- **WHEN** разметка использует атрибут `C4Component` без параметра описания
- **THEN** компиляция завершается ошибкой

#### Scenario: Значение по умолчанию для isRoot

- **WHEN** атрибут `C4Component` указан только с описанием
- **THEN** разметка компилируется, и узел не становится корневым

#### Scenario: Описание задано как null

- **WHEN** разметка передаёт `null` в качестве описания
- **THEN** описание считается незаданным, и узел не становится компонентом диаграммы

### Requirement: Совместимость версий пакета атрибутов

Публикация пакета SHALL следовать семантическому версионированию: изменение, делающее ранее
скомпилированный код потребителя несовместимым, SHALL сопровождаться увеличением мажорной
версии.

#### Scenario: Переименование пространства имён

- **WHEN** пространство имён атрибутов изменяется
- **THEN** выпускается новая мажорная версия пакета (прецедент: `C4ModelBuilder.Models.Attributes`
  заменено на `C4ModelBuilder.Attributes` в версии 2.0.0)

#### Scenario: Добавление совместимой возможности

- **WHEN** добавляется новый атрибут или необязательное свойство существующего атрибута
- **THEN** мажорная версия не увеличивается

#### Scenario: Обязательный параметр вместо свойства

- **WHEN** ранее скомпилированная разметка перестаёт компилироваться, например свойство
  заменяется обязательным параметром конструктора
- **THEN** выпускается новая мажорная версия пакета (прецедент: описание `C4Component` стало
  обязательным параметром конструктора в версии 3.0.0)
