## Why

Описание компонента задаётся необязательным свойством `Description`, поэтому разметка
`[C4Component]` без описания компилируется: узел анализируется, но на диаграмму не попадает,
и ошибка разметки обнаруживается только на готовой схеме. Обязательный параметр конструктора
превращает её в ошибку компиляции.

## What Changes

- **BREAKING**: `C4ComponentAttribute` получает обязательный параметр конструктора —
  `C4ComponentAttribute(string description, bool isRoot = false)`, а свойства `Description` и
  `IsRoot` становятся доступными только для чтения. Ранее скомпилированная разметка перестаёт
  компилироваться.
- Миграция разметки: `[C4Component(Description = "X")]` → `[C4Component("X")]`;
  `[C4Component(IsRoot = true, Description = "X")]` → `[C4Component("X", isRoot: true)]`.
- Параметр `description` объявляется не-nullable, а в репозитории диагностика `cs8625`
  (null-литерал для non-nullable) поднимается с предупреждения до ошибки — разметка репозитория
  не сможет передать `null`.
- Анализатор переходит на чтение аргументов конструктора (`ConstructorArguments`) вместо
  именованных аргументов: описание берётся из обязательного параметра, `isRoot` — из второго.
- Версия пакета `C4ModelBuilder.Attributes` поднимается с 2.0.1 до 3.0.0 (требование спеки
  о семантическом версионировании).

## Не входит в объём

- Поведение диаграммы: правила состава дерева вызовов, типизация компонентов, разрешение
  интерфейс → класс и CQRS не меняются; дельта `component-diagram-generation` не создаётся.
- Атрибуты уровней 1, 2 и 4 (`C4Context`, `C4Container`, `C4Code`) не трогаются.
- Переходный путь совместимости через `[Obsolete]`-свойства не создаётся: он сделал бы описание
  снова необязательным.
- Полный запрет `null` у потребителей: аргумент атрибута — константа, а nullability отвергается
  настройками их проекта, библиотека это гарантировать не может.
- Runtime-проверка в конструкторе и лог-предупреждение анализатора не добавляются: при
  отсутствующем описании узел просто не становится компонентом.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `c4-annotation-attributes`: меняются требования к разметке — описание становится обязательным
  параметром конструктора, `isRoot` — вторым параметром со значением по умолчанию `false`,
  свойства предоставляются только для чтения; добавляется прецедент мажорного подъёма версии.

## Impact

- Публичный контракт: `C4ComponentAttribute` — **breaking** для потребителей пакета; версия
  поднимается до 3.0.0. Публичный API библиотеки (структура проектов решения) не меняется.
- Код решения: `C4ModelBuilder.Attributes/C4ComponentAttribute.cs`,
  `C4ModelBuilder.Analyzer/Infrastructure/AttributeDataExtensions.cs`,
  `C4ModelBuilder.Sample.Target` (12 мест разметки), `C4ModelBuilder.Analyzer.Tests` (26 мест).
- Конвенции: `.editorconfig` — `dotnet_diagnostic.cs8625.severity` меняется с `warning` на `error`.
- Документация: `C4ModelBuilder/C4ModelBuilder.Attributes/README.md` — новый синтаксис и миграция.
- `openspec/specs/`: дельта `c4-annotation-attributes` (MODIFIED).
