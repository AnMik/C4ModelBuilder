## MODIFIED Requirements

### Requirement: Связи между компонентами

Связи SHALL устанавливаться между ближайшим компонентом-предком и вызванным компонентом.
Повторяющиеся связи SHALL выводиться один раз, связь компонента с самим собой SHALL NOT
создаваться. Вызов метода своего класса SHALL NOT создавать связь с классом: связь SHALL
устанавливаться между вызывающим компонентом и компонентом вызванного метода, а класс SHALL
оставаться компонентом-предком вызванного метода и его содержимого.

#### Scenario: Вызов компонентом самого себя

- **WHEN** компонент вызывает сам себя
- **THEN** связь компонента с самим собой не создаётся

#### Scenario: Вызов метода своего класса

- **WHEN** метод класса вызывает другой метод того же класса, и оба метода являются компонентами
- **THEN** выводится связь от вызвавшего метода к вызванному, связь от вызвавшего метода к классу не
  выводится, а класс остаётся компонентом-предком вызванного метода

#### Scenario: Вызов метода своего класса, не являющегося компонентом

- **WHEN** метод класса вызывает метод того же класса, который компонентом не является
- **THEN** связь не выводится, а класс остаётся компонентом-предком последующего содержимого

#### Scenario: Вызов нескольких компонентов

- **WHEN** один узел вызывает несколько разных компонентов
- **THEN** создаётся отдельная связь для каждого вызванного компонента

#### Scenario: Повторяющаяся связь

- **WHEN** одна и та же пара компонентов встречается в дереве несколько раз
- **THEN** в тексте диаграммы связь выводится один раз
