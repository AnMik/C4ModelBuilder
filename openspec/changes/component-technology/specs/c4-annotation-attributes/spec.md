# Spec Delta

## MODIFIED Requirements

### Requirement: Разметка компонента атрибутом C4Component

Пакет SHALL публиковать атрибут `C4ComponentAttribute` (`C4Component`), применимый к классу,
интерфейсу и методу. Описание SHALL быть обязательным первым параметром конструктора:
`C4ComponentAttribute(string description, bool isRoot = false, string? technology = null)`, где
`description` SHALL быть не-nullable. Корневой компонент SHALL задаваться вторым параметром
конструктора `isRoot` со значением по умолчанию `false`. Технология SHALL задаваться третьим,
необязательным параметром конструктора `technology`, который SHALL допускать отсутствие значения.
Свойства `Description`, `IsRoot` и `Technology` SHALL предоставляться только для чтения и SHALL
отражать значения параметров конструктора.

#### Scenario: Разметка корневого компонента

- **WHEN** класс помечен атрибутом `C4Component` со значением `isRoot = true`
- **THEN** разметка компилируется, и класс становится точкой входа анализа

#### Scenario: Разметка компонента с описанием

- **WHEN** тип помечен атрибутом `C4Component` со значением описания
- **THEN** указанный текст используется как описание компонента на сгенерированной диаграмме

#### Scenario: Разметка компонента на методе

- **WHEN** метод помечен атрибутом `C4Component` со значением описания
- **THEN** узел вызова этого метода становится компонентом диаграммы с указанным описанием

#### Scenario: Разметка без описания

- **WHEN** разметка использует атрибут `C4Component` без параметра описания
- **THEN** компиляция завершается ошибкой

#### Scenario: Значение по умолчанию для isRoot

- **WHEN** атрибут `C4Component` указан только с описанием
- **THEN** разметка компилируется, и узел не становится корневым

#### Scenario: Описание задано как null

- **WHEN** разметка передаёт `null` в качестве описания
- **THEN** описание считается незаданным, и узел не становится компонентом диаграммы

#### Scenario: Разметка компонента с технологией

- **WHEN** тип помечен атрибутом `C4Component` с описанием и значением `technology`
- **THEN** разметка компилируется, свойство `Technology` возвращает переданное значение, а указанный
  текст выводится на диаграмме как технология компонента

#### Scenario: Технология не задана

- **WHEN** атрибут `C4Component` указан без параметра `technology`
- **THEN** разметка компилируется, свойство `Technology` возвращает отсутствие значения, а диаграмма
  выводится без строки технологии

#### Scenario: Технология и корневой компонент заданы вместе

- **WHEN** класс помечен атрибутом `C4Component` со значениями `isRoot = true` и `technology`
- **THEN** разметка компилируется, класс становится точкой входа анализа, а технология выводится в его
  диаграмме

#### Scenario: Технология на методе

- **WHEN** метод помечен атрибутом `C4Component` с описанием и значением `technology`
- **THEN** узел вызова этого метода становится компонентом диаграммы с этой технологией

#### Scenario: Технология не наследуется методом от класса

- **WHEN** класс помечен атрибутом `C4Component` с технологией, а его метод — атрибутом `C4Component`
  без технологии
- **THEN** компонент метода выводится без строки технологии
